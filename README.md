Movie Database je konzolová aplikace napsaná v jazyce Python. Po spuštění vyzve uživatele k výběru jedné ze čtyř možností: přidání filmu, zobrazení kompletního seznamu filmů, vyhledávání filmů podle žánru nebo ukončení aplikace.

Aplikace provádí kontrolu veškerých uživatelských vstupů, aby předešla zadání neplatných údajů, jako jsou prázdná pole nebo nesprávné roky vydání. Obsahuje předdefinovanou sbírku filmů, přičemž filmy přidané uživatelem se ukládají pouze po dobu aktuální relace a po ukončení aplikace jsou odstraněny.

---------------------------------------------------------------------------------------------------------------------------

Movie Database is a console application written in Python. When started, it prompts the user to choose one of four options: add a movie, display the complete movie list, search movies by genre, or exit the application.

The application validates all user input to prevent invalid data, such as empty fields or incorrect release years. It comes with a predefined collection of movies, while any movies added by the user are stored only during the current session and are removed when the application is closed.
